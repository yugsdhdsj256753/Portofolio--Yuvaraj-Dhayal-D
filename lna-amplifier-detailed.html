1. Introduction: what is an LNA?

A low-noise amplifier (LNA) is an amplifier used near the beginning of a radio-frequency (RF) receiver chain. An antenna may deliver a very small signal, so the receiver needs to amplify it before later blocks such as mixers, filters and baseband circuits process it. The LNA should provide useful gain while adding as little noise and distortion as practical.

The LNA is especially important because noise added by the first receiver stage has a strong effect on the total receiver noise. A low-noise first stage can help preserve the signal-to-noise ratio before the signal reaches noisier downstream blocks.

Where does the LNA fit in a receiver?

Antenna → RF filter / matching → LNA → Mixer → Baseband / ADC

This is a simplified receiver chain; the exact order depends on the architecture. The LNA usually operates at RF, before frequency conversion. Its target band could be a wireless communication band, satellite receiver band, radar band or another RF application.

Why not simply use a high-gain amplifier?

High gain alone is not enough. An amplifier may have high gain but also add excessive noise, reflect input power, distort strong signals or become unstable. LNA design is therefore a multi-objective optimization problem involving noise figure, gain, matching, linearity, stability, bandwidth and power consumption.

3. Understanding the circuit

The illustrated topology is a cascode LNA with inductive source degeneration. M1 is the input common-source transistor, M2 is the common-gate cascode transistor, Lg and Ls help shape the input impedance, and Ld acts as the RF drain load. The schematic omits practical details such as bias networks, coupling capacitors, decoupling, pads and layout parasitics.

M1 — Common-source input device

The RF signal is applied to M1's gate. A small change in gate-source voltage changes the drain current. Around the chosen bias point, this is described by transconductance, gm.

id ≈ gm · vgs

This is a small-signal approximation. M1's size, bias current, parasitic capacitances and operating region affect its gain, noise and input capacitance.

M2 — Common-gate cascode device

M2's gate is held at a suitable bias voltage, Vbias, which is an AC ground when the bias node is properly bypassed. The RF signal is passed through M2 from its source-side node toward its drain.

The cascode reduces voltage swing at M1's drain, which can reduce Miller feedback and improve reverse isolation. M2 must have enough voltage headroom to remain in the intended operating region.

Ld — Drain inductor

Ld provides a frequency-dependent load instead of a simple resistor. It may resonate with the total output capacitance near the target band, producing a large impedance and useful voltage gain.

Real inductors have finite quality factor and parasitic capacitance, so their losses and self-resonance must be considered.

Lg — Gate matching inductor

Lg helps tune out the capacitive part of the input impedance at the target frequency. It is chosen together with Ls and the transistor's input capacitances rather than as an isolated component.

Its series resistance contributes loss, which can degrade gain and noise performance.

Ls — Source degeneration inductor

Ls creates local frequency-dependent feedback. As drain current changes, the source voltage changes, altering Vgs. This affects the input impedance and can help create the real component needed for a 50 Ω input match.

Unlike a simple resistive degeneration element, an ideal inductor does not dissipate average power. A real inductor does have series resistance.

Vbias — DC bias for M2

Vbias establishes the operating point of the cascode transistor. It should be stable and appropriately decoupled so RF energy does not leak into the bias network. Its value depends on the process, supply, device dimensions and desired headroom.

How does the signal travel through the circuit?

  1. The RF input reaches M1's gate through the input network.
  2. The changing gate-source voltage causes a small-signal drain-current variation in M1.
  3. M2 transfers this current variation toward the output while helping isolate the input device from output-voltage swings.
  4. Ld and the output capacitances determine the load impedance and frequency response.
  5. The output voltage is taken at the drain of M2, at the node marked OUT.

4. Input impedance and inductive source degeneration

Many RF systems use a nominal 50 Ω source and measurement environment. The LNA input is designed so that the source can deliver signal power efficiently while meeting the noise and bandwidth requirements. The input impedance is complex: it contains both a real part and a reactive part.

Why is the real part important?

The real part of the input impedance determines the resistive component seen by the source. In an inductively source-degenerated MOS input stage, the source inductor transforms transistor transconductance into a useful real input-impedance component. In a simplified model, the approximate relationship is:

Re{Zin} ≈ gm · Ls / Cgs

This expression is a common first-order approximation under simplifying assumptions. It neglects effects such as gate resistance, body effect, feedback capacitances, losses and higher-order parasitics. It is useful for intuition, not a substitute for simulation.

How do Lg and Ls tune the input?

  • Ls helps establish the real part of the input impedance and adds local feedback.
  • Lg is selected to compensate the input capacitive reactance near the operating frequency.
  • Cgs and other transistor parasitics strongly affect the resonant point.
  • Inductor Q, metal losses, layout coupling and pad capacitance shift the real result away from the ideal model.
Ideal LC resonance: f₀ = 1 / (2π√(LC))

This equation describes the resonance of an ideal lumped LC network. In the LNA, the relevant effective capacitance includes transistor and layout parasitics, so the exact resonant frequency must be found from the complete circuit.

What does input matching mean in practice?

For a reference impedance Z₀, the input reflection coefficient is:

S11 = Γin = (Zin − Z₀) / (Zin + Z₀)

When Zin equals Z₀, the ideal reflection coefficient is zero. In a 50 Ω system, the design goal is often to keep S11 sufficiently low in the target band. The required threshold is application-specific; no single number is mandatory for every LNA.

5. Gain and frequency response

Gain tells us how much the input signal is amplified. In RF design, forward transmission is commonly inspected using S21, which is measured with defined reference impedances. S21 is not always identical to the intrinsic voltage gain because it includes the effects of input/output matching and power transfer.

Why can an inductor increase gain?

An inductor can provide a high impedance at the operating frequency, particularly when it resonates with capacitance. Since a small-signal output voltage is approximately current multiplied by load impedance, a larger load impedance can increase voltage gain over a suitable band.

Av ≈ −gm · Zload

This is a simplified common-source gain relationship. In a cascode LNA, the effective load, cascode behaviour, parasitic capacitances, feedback and losses all influence the final gain. The negative sign indicates inversion in the ideal common-source voltage-gain model.

Bandwidth and resonance

A tuned LNA may provide its maximum gain near a resonant frequency, with gain falling away from that frequency. A high-Q network can provide stronger selectivity but narrower bandwidth. The designer chooses component values and loading to satisfy the required operating band, not simply to maximize peak gain.

6. Noise figure and major noise sources

Every physical amplifier adds noise. Noise figure describes the degradation of signal-to-noise ratio between input and output under the specified measurement conditions.

Noise factor F = SNRin / SNRout
NF (dB) = 10 log₁₀(F)

Noise factor is a linear ratio; noise figure is its value expressed in decibels. An ideal noiseless amplifier would have F = 1 and NF = 0 dB, but real devices and passive components introduce noise or loss.

Where does LNA noise come from?

  • MOS channel thermal noise: random carrier motion in the conducting channel; often a major device noise contribution.
  • Gate resistance noise: distributed gate resistance can matter at high RF frequencies and for wide devices.
  • Inductor and metal losses: finite series resistance adds thermal noise and reduces efficiency.
  • Bias-network noise: imperfect filtering can allow bias circuitry noise to couple into the signal path.
  • Substrate and parasitic effects: coupling and loss can degrade noise and gain, especially after layout.

How does the designer reduce noise?

Noise optimization involves choosing the transistor size and bias point, selecting a suitable input topology, reducing avoidable passive loss, and matching with awareness of the device's optimum noise impedance. The impedance that minimizes noise figure is not always exactly the impedance that gives the best power match, so the designer may need to balance both goals.

Important: Do not assume that the lowest S11 automatically produces the lowest noise figure. Input matching and noise matching are related but distinct design considerations.

7. S-parameters, linearity, stability and power

S11 — Input reflection

S11 indicates how much of an incident wave is reflected at the input under the S-parameter reference conditions. It is commonly displayed in dB. More negative S11 generally indicates less reflected power at that frequency.

S21 — Forward transmission

S21 measures forward transmission between the input and output ports. For an amplifier it is often used to assess gain versus frequency, provided the port impedances and measurement setup are understood.

S22 — Output reflection

S22 characterizes output matching. It matters because a poor output match can reduce power transfer to the following stage and interact with the input match.

S12 — Reverse transmission

S12 measures reverse transmission from output to input. A cascode stage often helps reduce reverse coupling, although the achieved isolation depends on device parasitics and layout.

Linearity: P1dB and IIP3

Real amplifiers are nonlinear. With sufficiently large input signals, gain compresses and new frequency components can appear. The 1-dB compression point (P1dB) identifies the input or output level at which gain has fallen by 1 dB from its small-signal extrapolation. The input third-order intercept point (IIP3) is a figure of merit derived from a two-tone test. These metrics help estimate how the LNA handles strong blockers and interferers.

Stability: K-factor and μ

An amplifier must not oscillate unintentionally. Stability should be checked across a broad frequency range, not only at the intended signal band. Rollett's K-factor is commonly used together with the determinant of the S-parameter matrix; μ and μ′ are alternative stability measures. The correct interpretation depends on the test conditions and network assumptions.

Power consumption

PDC ≈ VDD · IDD

This is the basic DC power relationship for a single supply rail and corresponding supply current. For multiple rails, sum the power from each supply. Report the supply voltage and total current alongside power so the result can be interpreted.

8. Practical RF simulation workflow

Step 1 — Write a specification

Record the target frequency band, supply voltage, gain, noise figure, input/output return loss, linearity, stability, bandwidth and power budget. Mark which values are hard requirements and which are goals.

Step 2 — Choose and bias the devices

Select the process, transistor dimensions and current density. Use DC operating-point analysis to inspect terminal voltages, drain currents and operating regions. Confirm that both the input transistor and cascode device have enough voltage headroom.

Step 3 — Design the matching and load networks

Use small-signal parameters and device noise information to select initial Lg, Ls and Ld values. Include estimated parasitic capacitance and realistic inductor models where available. Treat hand calculations as starting estimates, not final answers.

Step 4 — Run AC / S-parameter and noise analyses

Plot S11, S21, S12 and S22 over a wide enough frequency sweep. Run noise analysis to examine noise figure and identify dominant contributors. Tune component values and bias while watching all specifications together.

Step 5 — Verify large-signal performance

Run suitable compression and two-tone analyses for P1dB and IIP3. Check stability across a wide frequency range and consider realistic source and load impedances. Confirm that the circuit behaves properly during startup and across expected conditions.

Step 6 — Check corners and layout

Run process, voltage and temperature corners. Once layout is available, perform DRC and LVS, extract parasitics, and rerun post-layout RF and noise simulations. At RF, routing, coupling, substrate loss and inductor geometry can significantly change performance.

Reporting discipline: This article explains the topology and design process; it does not claim measured or simulated performance. Only publish numerical gain, NF, S11, frequency, power or linearity values that come from your own verified simulations or measurements.

9. Interview questions and key takeaways

Why use a cascode in an LNA?

It can improve reverse isolation and reduce the input transistor's drain-voltage swing, which reduces Miller feedback. The trade-off is extra voltage headroom and another device whose parasitics and noise must be considered.

Why use source degeneration?

An inductive source element provides local feedback and can create a useful real component in the input impedance, supporting matching while preserving the potential for low-noise operation. Its value also affects gain and bandwidth.

Does a better input match guarantee a better NF?

No. S11 describes input reflection; NF describes signal-to-noise degradation. The optimum noise impedance and the impedance for a perfect power match can differ.

Why is the LNA placed early in the receiver?

Because noise contributed by early stages strongly affects the receiver's overall noise performance. Adequate first-stage gain can reduce the relative contribution of later stages, provided the LNA itself has low noise and sufficient linearity.

Key takeaways

  • M1 converts input voltage variation into current variation; M2 provides cascode action and helps isolate the input.
  • Lg and Ls work with transistor parasitics to tune the input impedance.
  • Ld and output capacitance shape the gain and frequency response.
  • Gain, NF, matching, linearity, stability, bandwidth and power must be evaluated together.
  • Post-layout parasitics can change RF results, so final claims should be based on extracted simulations or measurements.
