MOSFET Common-Source Amplifier

Understanding the operation, gain, output resistance, loading techniques and source degeneration of the MOSFET common-source amplifier.

By Yuvaraj Dhayal D · Analog VLSI

1. Introduction

The MOSFET common-source amplifier is one of the most fundamental amplifier configurations in analog integrated circuit design.

In a common-source amplifier, the gate acts as the input terminal while the drain acts as the output terminal. The source terminal is common to the input and output signals, which gives the topology its name.

Key Idea

A small change in the input voltage produces a change in drain current. This current variation is converted into an output voltage through the load connected to the drain.

2. Basic Common-Source Amplifier

The simplest common-source amplifier can be constructed using an NMOS transistor with a resistor connected between the drain and the supply.

                RD

Basic NMOS common-source amplifier

When the input voltage increases, the MOSFET drain current increases. The voltage drop across the drain resistor therefore increases, causing the output voltage to decrease.

Therefore, the common-source amplifier provides voltage inversion.

3. Operation of the Common-Source Amplifier

The operation can be understood by considering the MOSFET operating regions.

Cutoff Region

When the input voltage is below the threshold voltage, the NMOS is approximately OFF.

VGS < VTH

The drain current is nearly zero and the output voltage approaches VDD.

Saturation Region

For amplification, the MOSFET is normally biased in the saturation region.

VDS ≥ VGS − VTH

In this region, a small variation in VGS produces a change in drain current. This transconductance action is responsible for voltage amplification.

Linear / Triode Region

When the drain voltage becomes sufficiently low, the transistor enters the linear region.

At this point, the amplifier no longer provides the desired high-quality amplification.

4. Small-Signal Model

For small variations around the bias point, the MOSFET can be represented using a small-signal model.

Important Parameters

  • gm — MOSFET transconductance
  • ro — MOSFET output resistance
  • RD — drain/load resistance
  • VGS — gate-source voltage
  • VDS — drain-source voltage

5. Voltage Gain

For a common-source amplifier with a resistive load, the small-signal voltage gain can approximately be written as:

AV ≈ −gm(ro || RD)

If channel-length modulation is neglected, ro becomes very large compared with the load resistance. The gain then becomes approximately:

AV ≈ −gmRD

The negative sign indicates that the output voltage is 180° out of phase with the input voltage.

6. MOSFET Transconductance

Transconductance describes how effectively a change in gate-source voltage controls the drain current.

gm = ∂ID / ∂VGS

For a long-channel MOSFET operating in saturation:

gm ≈ 2ID / VOV

where:

VOV = VGS − VTH

7. Input and Output Resistance

Input Resistance

Since the MOSFET gate ideally draws no DC current, the input resistance is very high.

RIN → ∞

Output Resistance

For a common-source amplifier with a drain resistor:

ROUT ≈ ro || RD

8. Different Types of Loads

The performance of the common-source amplifier strongly depends on the type of load connected to the drain.

Load Type Main Characteristic
Resistive Load Simple but consumes silicon area for large resistance
Diode-Connected MOSFET Compact but provides relatively low output resistance
Current-Source Load Higher gain due to larger output resistance
Active MOSFET Load High gain but can introduce nonlinear behavior

9. Diode-Connected MOSFET Load

A MOSFET can be configured as a diode-connected load by connecting its gate and drain together.

               |
              NMOS
               |
              GND

              ↑
             VIN

The diode-connected transistor provides a relatively low output resistance. As a result, this configuration generally provides lower gain than a high-output-resistance current-source load.

10. Current-Source Load

A current-source load can be implemented using another MOSFET biased with a fixed gate voltage.

Since both MOSFETs contribute output resistance, the approximate voltage gain is:

AV ≈ −gm,n (ro,n || ro,p)

The larger effective output resistance can provide significantly higher voltage gain.

11. Active Load

In integrated CMOS circuits, MOSFETs can replace large resistors and act as active loads.

For an active-load configuration, both NMOS and PMOS devices contribute to the small-signal behavior.

AV ≈ −(gm,n + gm,p) (ro,n || ro,p)

This topology is particularly important in CMOS analog integrated circuits because it can achieve high gain without requiring a physically large resistor.

12. Source Degeneration

A resistor can be inserted into the source terminal of the MOSFET to improve linearity. This technique is called source degeneration.

               |
              RD
               |
               +------ VOUT

              D

VIN ───────┤  NMOS│
           └──┬───┘
              S
              |
             RS

Source degeneration introduces local negative feedback. The source voltage changes in response to the drain current, reducing the effective variation of VGS.

The major trade-off is:

Gain vs Linearity

Increasing source degeneration generally improves linearity but reduces voltage gain.

13. Important Design Trade-offs

  • Increasing gm generally increases voltage gain.
  • Increasing the load resistance increases gain but can reduce the output swing.
  • Higher output resistance generally helps achieve higher gain.
  • Source degeneration improves linearity but reduces gain.
  • MOSFET active loads are useful for achieving high gain without large passive resistors.
  • The transistor must remain in the appropriate operating region for proper amplification.

14. Why Common-Source Amplifiers Matter in Analog IC Design

The common-source stage is one of the fundamental building blocks used to understand more complex analog circuits.

Concepts such as transconductance, output resistance, gain, biasing, frequency response, and feedback all appear in more advanced analog blocks.

Understanding the common-source stage therefore provides a strong foundation for studying operational amplifiers, differential amplifiers, current mirrors, bandgap references, LDOs and other analog IC building blocks.

15. Summary

Key Takeaways

  • The gate is the input and the drain is the output.
  • The common-source amplifier provides voltage inversion.
  • The approximate gain is −gm(ro || RD).
  • Higher transconductance and output resistance generally increase gain.
  • Active loads are widely used in CMOS analog IC design.
  • Source degeneration improves linearity at the expense of gain.
