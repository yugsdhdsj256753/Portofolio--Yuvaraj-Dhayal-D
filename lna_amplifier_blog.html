Understanding a Cascode Low-Noise Amplifier (LNA)

How a common-source input transistor, common-gate cascode device, and inductive matching network help amplify weak RF signals while controlling noise and reflections.

By Yuvaraj Dhayal D · Analog/Mixed-Signal IC Design

1. What is an LNA?

A Low-Noise Amplifier (LNA) is commonly placed near the front end of an RF receiver. It amplifies a weak signal from an antenna while adding as little noise as practical. Since the first receiver stage strongly influences overall receiver sensitivity, designers balance noise figure, gain, input matching, linearity, power consumption, and stability.

2. How does this cascode LNA work?

M1 — Common-source stage

The input RF signal is applied to the gate of M1. Its transconductance converts the small input voltage into a drain-current variation. M1 is usually a major contributor to the LNA's gain and noise performance.

M2 — Common-gate cascode

M2 is biased at its gate by Vbias. It helps isolate the input transistor from output-voltage swings, reduces the effect of Miller feedback, and improves reverse isolation and stability.

Ld — Inductive load

The drain inductor provides a frequency-dependent load. Near the intended operating band, resonance with output capacitances can create a high impedance and increase voltage gain.

3. Why are Lg and Ls used?

Lg and Ls form an inductive input-matching network with the transistor's parasitic capacitances.

  • Lg (gate inductor): helps tune the input network to the target RF frequency.
  • Ls (source degeneration inductor): introduces frequency-dependent feedback and helps set the real part of the input impedance, supporting input matching while avoiding a noisy series matching resistor.
  • Design goal: match the source—often a 50 Ω RF system—at the desired frequency while preserving a low noise figure.

This is the ideal LC resonance relation. A real LNA's resonant frequency and input impedance also depend on transistor parasitics, inductor losses, layout, and loading.

4. Key LNA metrics to evaluate

Gain — S21

Measures forward transmission. The target gain must be achieved across the intended frequency band.

Noise figure (NF)

Quantifies degradation in signal-to-noise ratio. Lower NF is generally desirable.

Input matching — S11

Shows how much input power is reflected. A common RF goal is good matching around the design frequency.

Linearity — IIP3 / P1dB

Indicates how well the LNA handles stronger signals without excessive distortion or gain compression.

Stability — K / μ

Stability factors help determine whether the amplifier may oscillate under different source and load conditions.

Power consumption

Bias current and supply voltage determine DC power, creating a trade-off with gain, noise, and linearity.

5. Practical design workflow

  1. Define the operating frequency, supply voltage, gain, noise figure, matching, linearity, and power targets.
  2. Choose the process and transistor dimensions; establish a suitable DC operating point.
  3. Design the input matching network using the transistor's small-signal and noise characteristics.
  4. Tune Lg, Ls, and Ld, then simulate S-parameters, noise figure, gain, and stability.
  5. Run corners and, where applicable, layout extraction and post-layout simulations before reporting final performance.
Important: The schematic is a topology reference, not a set of measured results. Do not claim a particular gain, noise figure, or operating frequency unless it has been verified in simulation or measurement.

Key takeaway

A cascode LNA combines the gain capability of a common-source input device with the isolation benefits of a common-gate cascode. Inductive source degeneration and input tuning help achieve useful RF matching and noise performance, but the final result depends on careful device sizing, biasing, parasitics, and simulation.
